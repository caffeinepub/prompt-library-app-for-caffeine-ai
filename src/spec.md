# Specification

## Summary
**Goal:** Fix category display to show all categories in a responsive grid layout that wraps to multiple rows.

**Planned changes:**
- Convert category filter bar from horizontal scroll to responsive grid layout that wraps categories to new rows
- Ensure all 22-23 categories are visible simultaneously on screen without horizontal overflow
- Position Favorites and Create Category buttons at the start of the category list, followed by all user categories
- Maintain responsive behavior across different screen sizes

**User-visible outcome:** Users can see all their categories at once in a grid layout below the search bar, with categories wrapping to multiple rows instead of scrolling horizontally off-screen.
